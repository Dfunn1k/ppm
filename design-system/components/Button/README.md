Botones de acción, en tres variantes.

- `primary`: la única acción principal de la pantalla («Registrar gasto»). Fondo `primary`, texto `primary-foreground`.
- `secondary`: acciones de apoyo («Cancelar», «Filtrar»). Fondo `secondary`.
- `destructive`: borrar o archivar. Fondo `destructive`, texto `destructive-foreground`. Pide confirmación dentro de la propia pantalla.
- Alto 40px, `radius-md`, texto `body-strong`. Un ícono opcional a la izquierda, a 20px.
- El texto dice exactamente lo que pasa al tocarlo.
