El ícono redondo de una categoría, con su nombre al lado, para filas de movimientos y selectores.

- Recibe el nombre del ícono de Material Symbols (`account_account.icon`) y el índice de color 0 a 11 (`account_account.color`, ya resuelto con la herencia del padre).
- Fondo `cat-<índice>`, ícono en `on-category`, círculo de 36px con `radius-full`.
- El nombre va en `body-strong` y, debajo, la categoría padre en `caption` y `muted-foreground`.
- Nunca uses el color de categoría para texto ni para estados.
